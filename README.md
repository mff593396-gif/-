# خلاصة الفكرة

موقع خدمات طلابية ومعرفية في ملف واحد: `index.html`. الطلبات تُرسل عبر واتساب، وبيانات كل زائر (السلة، الطلبات، النقاط) تُحفظ في متصفحه فقط.

## النشر على الإنترنت (GitHub Pages)

مرة واحدة فقط:

1. اجعل المستودع عاماً: **Settings ← General ← Danger Zone ← Change visibility ← Public**.
2. فعّل النشر: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
3. ادمج التعديلات في فرع `main`.

بعدها يُنشر `index.html` تلقائياً مع كل دمج في `main`، على الرابط:
`https://mff593396-gif.github.io/-/`

ملف النشر في `.github/workflows/pages.yml` ينشر `index.html` وحده. مجلد `tools/` ومجلد `.claude/` لا يُنشران.

## نظام النقاط

- إرسال الطلب لا يضيف أي نقطة. تظهر للعميل "نقاط متوقعة" فقط.
- بعد تسليم الطلب واستلام المبلغ، يرسل صاحب المشروع للعميل **رابط تأكيد موقّع** في واتساب. بضغطة تُضاف النقاط لرصيده.
- الرابط موقّع بمفتاح خاص (ECDSA P-256) لا يملكه إلا صاحب المشروع، والموقع يتحقق منه بالمفتاح العام فقط. لذلك لا يمكن تزوير رابط، ولا تعديل عدد نقاطه، ولا احتساب الطلب نفسه مرتين.
- الـ 50 نقطة الترحيبية تُضاف مع أول طلب مكتمل.
- عند الاستبدال يظهر الكوبون في رسالة الطلب، ويتحقق صاحب المشروع من رصيد العميل في سجل الأداة قبل اعتماد الخصم.

### تشغيل الأداة (مرة واحدة)

1. نزّل `tools/points-signer.html` وافتحه في Chrome أو Edge على جهازك. يُفضَّل الكمبيوتر مع واتساب ويب.
2. اضغط **إنشاء مفتاح جديد**، ثم **تنزيل نسخة احتياطية** واحفظها في مكان آمن.
3. انسخ سطر المفتاح العام وضعه مكان `POINTS_PUBLIC_KEY: null,` في `index.html`. المفتاح العام ليس سراً، ويمكن إرساله لمن يعدّل الموقع.

### الاستخدام اليومي

- **بعد تسليم طلب:** أدخل جوال العميل وكود الطلب والمبلغ، ثم **إنشاء الرابط** ← **أرسله للعميل في واتساب**.
- **لتحديث حالة طلب** (مراجعة، تنفيذ، تسليم): من قسم "رابط تحديث حالة الطلب".
- **عند طلب استبدال:** اكتب جوال العميل ← **عرض الرصيد**. إن كان كافياً اضغط **تسجيل استبدال** واعتمد الخصم.

> المفتاح الخاص وسجل النقاط محفوظان في متصفح الأداة. لو مُسحت بيانات المتصفح استوردهما من النسخة الاحتياطية.

## الأمان

- **سياسة أمان المحتوى (CSP):** لا يُنفَّذ إلا سكربتا الصفحة ببصمتيهما، ولا تُحمَّل موارد خارجية إلا خطوط Google.
- **حماية من حقن الأكواد (XSS):** كل نص يكتبه المستخدم يُعرض بعد تهريبه.
- **روابط واتساب:** تُفتح دون صلاحية الوصول للصفحة الأصلية.
- **لا أسرار في كود الموقع:** لا كلمات مرور ولا مفاتيح خاصة.
- **بعد تعديل أي سكربت في `index.html` محلياً**، شغّل:

  ```
  python3 tools/update-csp.py
  ```

  ملف النشر يعيد حساب البصمات تلقائياً أيضاً.

### حدود معروفة

لأن الموقع بلا خادم:

- **حد الـ 15 طلباً يومياً:** يُطبَّق لكل جهاز على حدة. هو حماية من الإرسال المتكرر، وليس عدّاداً عاماً.
- **الرصيد المعروض للعميل:** محفوظ في متصفحه ويمكنه تعديله يدوياً. لذلك المرجع عند الاستبدال هو سجل الأداة.
